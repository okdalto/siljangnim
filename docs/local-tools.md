# 내 컴퓨터에서 도구 실행하기

[English](en/local-tools.md)

씬은 브라우저 안에서 돌지만, 브라우저가 잘 못하는 일은 에이전트가 내 컴퓨터에서 직접 실행합니다.
메시 처리(trimesh), 오디오 분석(librosa), 플로터 경로(vpype), 영상 변환(ffmpeg), ML 모델 같은 일입니다.
데스크톱 앱이나 MCP로 연결했을 때만 됩니다. 웹 버전에서는 안 됩니다.

## 무엇을 실행하나요

- **Python 패키지** — 필요한 패키지를 설치하고 에이전트가 쓴 코드를 실행합니다.
- **설치된 프로그램** — ffmpeg, Blender, OpenSCAD, ImageMagick, Inkscape, vpype, potrace 같은 프로그램이 이미 깔려 있으면 씁니다.

결과 파일은 프로젝트 **에셋**으로 들어오고, 씬이 그 파일을 씁니다. 오래 걸리는 작업은 **Jobs** 탭에서 보고 멈출 수 있습니다.

## 먼저 물어봅니다

다음 경우에는 실행 전에 허락 카드가 뜹니다.

- 이 프로젝트에서 Python 코드를 처음 실행할 때
- 새 패키지(버전 포함)를 설치할 때
- 새 프로그램을 실행할 때

**Allow for this project**(이 프로젝트에서는 계속 허용), **Allow once**(이번만), **Deny**(거부) 중에 고르세요.
카드는 내장 에이전트면 채팅에, 외부 에이전트면 Activity 탭에 뜹니다.

## 어디에 설치되나요

- 패키지 묶음마다 따로 만든 Python 환경에 설치합니다. 내 컴퓨터의 Python이나 다른 프로젝트는 건드리지 않습니다.
- 위치: 데스크톱 앱은 앱 데이터 폴더(macOS `~/Library/Application Support/Siljangnim/runtime`), MCP는 `~/.siljangnim/runtime`.
- 처음 쓸 때 Python을 한 번 받습니다(약 120 MB).

## 주의

파일과 의존성을 따로 두는 것이지 **OS 샌드박스는 아닙니다.** 실행된 코드는 내가 직접 실행한 프로그램처럼 내 파일에
접근할 수 있습니다. 그래서 먼저 묻습니다. 내용을 모르겠으면 거부하고 에이전트에게 무엇을 하려는지 물어보세요.

## 레시피

한 번 성공한 방법은 **레시피**로 저장됩니다. 어떤 패키지를 어떻게 설치하고 어떻게 불렀는지 적은 짧은 md 파일입니다
(`~/Siljangnim/recipes/<id>/recipe.md`). 다음에 비슷한 걸 요청하면 바로 실행되고, 다른 사람과 나눌 수도 있습니다.
[공유하기](sharing.md#레시피-나누기)를 보세요.
