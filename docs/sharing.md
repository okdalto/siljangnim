# 공유하기

[English](en/sharing.md)

## 프로젝트 내보내기

프로젝트 메뉴(상단 프로젝트 이름 옆)에서:

- **Export project (.zip)** — 프로젝트 전체를 묶습니다: `project.md`, 미리보기 이미지, 코드(`code/`), 에셋, 쓴 레시피.
- **Import project (project.md or .zip)…** — 받은 파일을 새 프로젝트로 엽니다.

**에셋** 탭에서는 씬의 코드와 셰이더를 바로 읽을 수 있고, 아래 버튼으로 프로젝트를 파일로 꺼낼 수 있습니다.
데스크톱 앱에서는 `~/Siljangnim/projects/` 아래 폴더에 쓰고 Finder(탐색기)로 열어 줍니다. 웹에서는 zip으로 받습니다.
꺼낸 파일은 사본이라, 고쳐도 프로젝트에는 반영되지 않습니다.

## project.md

`project.md`는 코드보다 **만든 방법**을 담은 문서입니다. 받은 사람의 에이전트가 이 문서를 보고 프로젝트를 다시 만듭니다.

```
# 제목
## Intent            처음에 무엇을 요청했는지
## Assets            에셋 목록과 출처(직접 넣은 것 / 몇 번째 단계에서 만든 것)
## Pipeline          단계마다 쓴 패키지(정확한 버전), 입력, 출력, 코드
## Scene             씬 전체
## Rebuilding        다시 만드는 순서
```

- md만 보내도 됩니다. 에셋이 없으면 가져올 때 무엇이 빠졌고 어떻게 다시 만드는지 알려 줍니다.
- 가중치 라이선스가 있는 모델을 썼다면 사용 조건도 적힙니다.
- 에이전트에게 "이 프로젝트를 project.md로 내보내 줘"라고 해도 됩니다.

## 레시피 나누기

레시피는 이 저장소의 [registry/](../registry/)에서 함께 씁니다. 에이전트는 필요한 도구를 찾을 때 여기서도 찾아보고, 받아서 씁니다.

- 받은 레시피는 이 컴퓨터에서 처음 실행할 때 다시 허락을 묻습니다. 파일이 바뀌었으면(체크섬이 다르면) 설치하지 않습니다.
- **기여하기:** `~/Siljangnim/recipes/<id>/recipe.md`를 `registry/recipes/<id>/`에 복사하고, `hub/` 폴더에서
  `python -m siljangnim_hub.registry build ../registry`로 목록을 다시 만든 뒤 PR을 보내 주세요.
  레시피에는 연결 코드만 들어갑니다. 다른 사람의 코드는 패키지 이름과 버전으로만 적습니다.

## 예제 링크

예제마다 **Link** 버튼이 있습니다. 링크를 열면 그 예제가 바로 열립니다(예: `siljangnim.vercel.app/#example=oss-three`).
