# 실장님으로 만들기

[English](en/creative.md)

실장님은 받아서 돌려 보는 예제 모음이 아니라 **작업실**입니다. 말로 시작하고, 대화하며 다듬고, 다른 작업과 섞고,
무대에서 연주하고, 영상으로 뽑습니다. 코드는 에이전트가 쓰고, 방향은 내가 정합니다.

## 1. 말로 시작하기

"어두운 바다를 떠다니는 해파리", "이 사진으로 깊이에 따라 밀도가 달라지는 해칭" 처럼 결과를 말하세요.
에이전트가 필요한 도구(셰이더, 물리 엔진, 기하 라이브러리, Python 패키지, ML 모델)를 고르고, 씬을 쓰고,
실행해서 오류를 고치고, 화면을 직접 캡처해 보고 나서 답합니다.

예제에서 시작해도 됩니다. **Examples**에서 아무 작품이나 열면 그대로 내 프로젝트가 됩니다.

D3·Three.js·p5.js·ngraph처럼 같은 라이브러리와 관련 확장 도구의 예제는 폴더로 묶여 있습니다.
폴더를 눌러 펼치고, 검색하면 일치하는 예제가 자동으로 보입니다. 리믹스 선택창에서도 같은 방식으로 찾을 수 있습니다.
폴더를 펼치는 것만으로 예제 파일을 내려받지는 않습니다.

OpenCV 폴더에는 윤곽 드로잉 외에 네 모서리를 지정하는 원근 보정, 두 프레임 사이의 점 추적, 지정한 마스크 안의 긁힘 복원이 있습니다. Reveal result로 입력과 실제 계산 결과를 비교하세요. FFmpeg 폴더에서는 장면 전환과 2배속 편집을 기준 영상과 나란히 비교할 수 있습니다. 모두 직접 실행한 결과와 재실행 레시피를 포함하며, 화면의 조절기는 저장된 결과를 비교합니다. 처리 조건을 바꾸려면 레시피를 다시 실행하세요.

FFmpeg 데이터모쉬는 2초 지점의 I-frame을 실제로 제거한 예제입니다. 왼쪽 원본과 오른쪽 처리 결과가 0~2초에는 같고 2~5초에는 달라지며, 5초에서 복구됩니다. Play를 0으로 바꾸고 Inspect time으로 같은 시점의 프레임을 비교하세요. 앱에는 정상 MP4로 다시 인코딩한 결과만 제공하며, 손상된 중간 영상은 레시피의 임시 폴더에서만 만듭니다.

처음 열 때 그 예제의 장면과 준비된 이미지·오디오·데이터를 내려받습니다. 카드에서 용량을 확인하고,
다운로드 중에는 진행률을 보거나 취소할 수 있습니다. 한 번 받은 파일은 이 브라우저/앱에 저장되어 다음부터 재사용합니다.
실패하거나 취소했다면 다시 열어 재시도하세요. 이미 받은 정상 파일은 다시 받지 않습니다.
**다운로드 캐시 삭제**는 내려받은 예제 파일만 지우며, 이미 만든 프로젝트는 유지합니다.

AI 예제를 보는 것만으로 대형 모델이나 도구를 설치하지 않습니다. 직접 재생성할 때 따로 준비합니다.
저장된 예제 파일은 오프라인에서도 재사용하지만, 외부 JS 라이브러리·카메라·온라인 서비스가 필요한 예제는 별도 조건이 필요합니다.
브라우저의 사이트 데이터 삭제나 저장 공간 정리로 캐시가 사라지면 다시 내려받습니다.

셰이더 예제는 라이선스와 함께 포함된 원본 GLSL로 실행합니다. MuJoCo·VTK·PyVista·Taichi·FiPy·NEURON 등의 예제는 직접 계산한 결과를 불러옵니다. 이때 컨트롤은 저장된 시간 단계나 결과를 선택하며, 계산 입력을 바꾸려면 포함된 레시피를 다시 실행합니다. U²Net·YOLO 모델은 재실행 시에만 내려받아 캐시합니다. nanoGPT는 작은 원본 문장 집합으로 직접 학습한 손실 곡선과 생성 결과를 보여 줍니다. Mitsuba의 CPU 렌더, Draco 압축·xatlas UV 펼치기·libigl 변형, 폰트 조형·래스터화, JPEG 압축과 PySSTV 신호도 직접 계산한 결과로 비교할 수 있습니다. Go의 gg·ln·pt 렌더와 단백질 리본, C/C++의 볼록 껍질·다각형 분할·스파이로 곡선도 포함합니다. Go 모듈과 C/C++ 원본 소스는 재실행할 때만 다운로드해 캐시합니다. C/C++ 레시피는 소스 체크섬을 검증하며 로컬 컴파일러가 필요합니다. SDF 표면, 로봇 경로, 디더링·삼각형 근사·내용 기반 이미지 축소 예제에는 직접 실행한 결과와 재실행 레시피가 있습니다.

FastNoise Lite·libnoise 지형, Voro++ 셀, RVO2 이동 경로, Skeleton Tracing 중심선과 MSDFgen 거리장도 원본 C++를 직접 실행한 결과입니다. DaisySP·Maximilian·Pink Trombone 예제에서는 직접 합성한 1초 음원을 선택해 들을 수 있습니다.

Laya는 원본 영어 모델이 세 문의를 분류한 실제 확률을 보여 줍니다. Sonic Pi 예제는 원본 악기 정의 세 종류로 직접 만든 여섯 음 구절을 오프라인 렌더해 들려줍니다. Sonic Pi의 언어 편집기가 아닌 악기 합성 부분을 실행합니다.

Geant4는 원본 엔진으로 세 두께의 물에서 전자의 이동과 에너지 전달을 계산합니다. Python 연결부의 종료 충돌을 피하기 위해 각 조건을 별도 프로세스에서 실행합니다. This product includes software developed by Members of the Geant4 Collaboration ( http://cern.ch/geant4 ).

redner는 원본 CPU 렌더링의 미분값으로 삼각형을 목표 이미지에 맞추는 과정을 보여 줍니다. 전용 Intel Python과 엔진은 검증 후 캐시하며, Apple Silicon에서는 Rosetta 2가 필요합니다.

PhysX는 NVIDIA GPU 없이 원본 CPU 물리 엔진으로 상자 36개의 낙하와 충돌을 계산합니다. Repulsive Curves는 원본 에너지·기울기로 매듭 곡선을 다듬으며, 자체 반복 최적화 입력을 사용합니다. 두 예제 모두 실제 실행 결과 세 장을 비교하고 레시피로 다시 계산할 수 있습니다.

Qwen3-TTS는 이 Mac의 CPU에서 직접 합성한 세 기본 목소리를 듣고 파형을 비교하는 예제입니다. 공식 모델 약 2.5GB는 레시피 실행 때만 받아 캐시합니다. 문장을 바꾸고 다시 실행하면 새 음성을 만들 수 있습니다.

openFrameworks는 원본 C++ 라이브러리의 노이즈·메시·OpenGL 기능으로 세 지형을 직접 그립니다. 첫 레시피 실행 때 공식 배포본을 내려받고 빌드한 앱을 캐시합니다. 재실행에는 macOS 그래픽 세션과 Xcode 빌드 도구가 필요합니다.

Tidal Cycles는 원본 Haskell 패턴 엔진으로 리듬의 기본·두 배 속도·역순 사건 시간을 계산합니다. 두 번 뒤집으면 원본으로 돌아오는지도 검증합니다. 소리 합성이 아닌 시간표 비교 예제이며, 재실행에는 GHC가 필요합니다.

TripoSR는 직접 만든 의자 그림 한 장에서 원본 모델로 입체와 색을 복원합니다. 입력과 세 방향의 원본 렌더를 비교하고 추출된 mesh.ply를 확인할 수 있습니다. 약 1.68GB 모델을 필요할 때 받아 캐시하며, CPU 재실행에는 C++ 빌드 도구가 필요합니다. 보이지 않는 면은 모델의 추론 결과입니다.

LivePortrait는 공개 사용 가능한 NASA 사진을 미리 자른 입력으로 사용해, 원본 모델에서 세 방향의 얼굴 이미지를 생성합니다. 실제 촬영 사진과 구분되도록 AI 생성 결과임을 표시합니다. 공식 모델 약 522MB를 필요할 때 받아 캐시하며 CPU에서 다시 실행할 수 있습니다. 자동 얼굴 검출이나 구동 영상 분석은 포함하지 않습니다.

Stable Audio Tools는 공개 Harmonai 학습 모델과 원본 DDIM 샘플러로 세 가지 짧은 스테레오 소리를 생성합니다. 모델 약 886MB를 필요할 때 받아 캐시하고 CPU에서 다시 실행합니다. 문장으로 음악을 지시하는 예제가 아닌, 시드별 소리 질감 비교입니다.

ACE-Step 1.5는 문장으로 지시한 피아노·타악기·신시사이저 연주를 각각 10초씩 생성합니다. 원본 모델을 Apple Silicon에서 실행한 결과이며, 재실행할 때 모델 약 6.34GB를 받아 캐시합니다. 의존성과 임시 메모리를 포함해 디스크 여유 20GB 이상을 권장합니다.

OpenSplat은 원본 CPU 학습기로 가우시안 96개를 목표 그림에 맞추고 초기·중간·최종 결과를 비교합니다. 원본 엔진과 OpenCV를 처음 실행할 때 컴파일해 캐시합니다. Xcode C++ 도구가 필요하며, 여러 사진에서 3D 장면을 복원하는 예제는 아닙니다.

VoiceStudio는 원본 KittenTTS 음성 생성 백엔드로 같은 영어 문장을 세 기본 목소리로 읽습니다. 약 82MB의 공개 모델을 필요할 때 받아 캐시하며 CPU에서 재실행합니다. 별도 목소리 샘플이나 API 키가 필요하지 않습니다. 앱 전체의 편집·더빙 기능은 이 예제에 포함하지 않습니다.

MT3: 공식 모델 약 172MB를 필요할 때 받아 캐시합니다. 직접 만든 3.2초 소리 세 개와 원본 모델이 추정한 MIDI를 비교합니다. 음높이 집합의 재현율은 100%·100%·75%였으며, 끝나는 시각과 악기 추정에는 오차가 있습니다. 추정 음표를 수동으로 고치지 않았으며 합주 음원의 성능을 검증한 예제는 아닙니다.

Nerfstudio: 합성한 색 구체를 -25·0·25도에서 본 24×24 입력 세 장으로 원본 NeRF를 2,000회 학습합니다. 학습 오차는 처음보다 90% 이상 줄어들지만 저해상도 결과에는 흐림과 잔상이 남습니다. 학습에 쓰지 않은 시점의 정확도나 실제 사진 재구성을 검증한 예제는 아닙니다. 원본 모델 생성자가 요구하는 AlexNet 가중치 약 244MB를 캐시하며, 화면의 결과는 NeRF가 직접 계산합니다.

CogVideoX: 직접 만든 96×96 크기의 아홉 프레임 애니메이션을 공식 영상 VAE로 인코딩하고 디코딩했습니다. 공식 예제 함수를 수정하지 않고 CPU·float32로 호출하며 시드는 17입니다. 약 862MB의 공개 모델을 필요할 때 받아 캐시합니다. 영상 생성기의 압축·복원 부분을 실행한 예제이며, 문장으로 새 영상을 만드는 확산 모델은 실행하지 않습니다.

LTX-Video: 직접 만든 128×128 크기의 17프레임 영상을 원본 VAE로 압축하고 복원합니다. 시드는 17, 디코딩 시점은 깨끗한 잠재값에 해당하는 0이며 CPU·float32로 실행합니다. 공식 체크포인트에서 필요한 가중치 약 2.49GB만 부분 다운로드하고 각 구간과 최종 파일의 해시를 확인해 캐시합니다. 전체 원본 체크포인트와 잠재값·복원 이미지가 일치했습니다. 첫 캐시 준비에는 여유 공간 약 6GB가 필요합니다. 문장으로 영상을 생성하는 확산 모델은 이 예제의 범위에 포함하지 않습니다.

### Shadertoy 코드 가져오기

Shadertoy 셰이더 코드를 채팅에 붙여 넣고 "이걸 돌려 줘", "이걸 지금 장면에 섞어 줘"라고 해도 됩니다. Image 탭뿐 아니라
Common, Buffer A–D, iChannel 연결도 그대로 돌아갑니다(`ctx.utils.shadertoy`).

단, **오픈소스 라이선스가 적힌 셰이더만** 씁니다. Shadertoy의 기본 라이선스는 CC BY-NC-SA 3.0(비상업)이라 오픈소스가
아닙니다. 코드 맨 위에 MIT, CC0, Unlicense, 퍼블릭 도메인, Apache-2.0, BSD 같은 라이선스가 적혀 있을 때만 에이전트가
옮기고, 작성자와 링크, 라이선스를 코드와 대화에 남깁니다. 라이선스가 없으면 그 사실을 알려 주고 비슷한 느낌의 새 셰이더를
제안합니다.

## 4. 라이브로 연주하기

- **입력:** 마우스와 키보드, 마이크와 오디오 파일(스펙트럼, 대역), 카메라, MIDI 컨트롤러, OSC(TouchOSC, Ableton,
  TouchDesigner 등). "MIDI 노브 1번으로 색을, 2번으로 속도를" 처럼 말하면 에이전트가 연결합니다. OSC는 데스크톱 앱이나 MCP에서 됩니다.
- **Perform:** 뷰포트 오른쪽 아래 **Perform**을 누르면 장면만 전체 화면으로 띄웁니다. 프로젝터나 두 번째 모니터로 보내고,
  컨트롤 패널과 MIDI·OSC·오디오로 연주하세요. Esc로 나옵니다.
- **Timeline:** 정해진 길이로 연출하려면 Timeline으로 바꾸고 컨트롤 값에 키프레임을 찍습니다.

## 5. 화면 비율과 영상으로 뽑기

뷰포트 오른쪽 아래 프레임 메뉴에서 화면 모양을 고릅니다: 창에 맞추기(Fit), 가로 16:9·4:3, 세로 9:16·4:5, 정사각형 1:1,
또는 1920×1080, 1080×1920, 3840×2160 같은 정확한 해상도, 직접 입력(예: `1280x720`, `21:9`). 정확한 해상도를 고르면 장면이
그 픽셀 수 그대로 렌더링됩니다. 프로젝트마다 기억합니다. 에이전트가 쓰는 장면은 중간에 크기가 바뀌어도(창 크기, Perform, 프레임 변경)
알아서 다시 맞추도록 만들어집니다.

**Rec** 버튼(또는 에이전트에게 "10초짜리 세로 영상으로 뽑아 줘")으로 녹화합니다.

- **Offline:** 처음부터 프레임 하나하나를 정확히 렌더링합니다. 원하는 크기(예: 1080×1920 세로, 4K)와 fps로, 느린 장면도 끊김 없이. MP4, WebM, PNG 연속 이미지.
- **Realtime:** 지금 화면을 그대로 녹화합니다. 마우스와 MIDI로 연주한 그대로 남습니다(WebM).

장면이 노래나 소리 파일을 틀고 있으면 그 소리가 영상에 함께 들어갑니다. 타임라인을 멈추거나 옮기면 노래도 같이
멈추고 옮겨집니다. Offline 녹화는 각 프레임 시점의 소리를 분석하므로, 소리에 반응하는 장면도 영상에서 박자가 맞습니다.
노래 한 곡으로 뮤직비디오를 만들 때 따로 소리를 합칠 필요가 없습니다.

녹화한 영상은 프로젝트 에셋으로도 남아서, 다른 장면의 재료로 다시 쓸 수 있습니다. 이 저장소의 소개 영상도 예제들을 이렇게 녹화해서 만들었습니다.
