# 실장님으로 만들기

[English](en/creative.md)

실장님은 받아서 돌려 보는 예제 모음이 아니라 **작업실**입니다. 말로 시작하고, 대화하며 다듬고, 다른 작업과 섞고,
무대에서 연주하고, 영상으로 뽑습니다. 코드는 에이전트가 쓰고, 방향은 내가 정합니다.

## 1. 말로 시작하기

"어두운 바다를 떠다니는 해파리", "이 사진으로 깊이에 따라 밀도가 달라지는 해칭" 처럼 결과를 말하세요.
에이전트가 필요한 도구(셰이더, 물리 엔진, 기하 라이브러리, Python 패키지, ML 모델)를 고르고, 씬을 쓰고,
실행해서 오류를 고치고, 화면을 직접 캡처해 보고 나서 답합니다.

예제에서 시작해도 됩니다. **Examples**에서 아무 작품이나 열면 그대로 내 프로젝트가 됩니다.

처음 열 때 그 예제의 장면과 준비된 이미지·오디오·데이터를 내려받습니다. 카드에서 용량을 확인하고,
다운로드 중에는 진행률을 보거나 취소할 수 있습니다. 한 번 받은 파일은 이 브라우저/앱에 저장되어 다음부터 재사용합니다.
실패하거나 취소했다면 다시 열어 재시도하세요. 이미 받은 정상 파일은 다시 받지 않습니다.
**다운로드 캐시 삭제**는 내려받은 예제 파일만 지우며, 이미 만든 프로젝트는 유지합니다.

AI 예제를 보는 것만으로 대형 모델이나 도구를 설치하지 않습니다. 직접 재생성할 때 따로 준비합니다.
저장된 예제 파일은 오프라인에서도 재사용하지만, 외부 JS 라이브러리·카메라·온라인 서비스가 필요한 예제는 별도 조건이 필요합니다.
브라우저의 사이트 데이터 삭제나 저장 공간 정리로 캐시가 사라지면 다시 내려받습니다.

셰이더 예제는 라이선스와 함께 포함된 원본 GLSL로 실행합니다. MuJoCo·VTK·PyVista·Taichi·FiPy·NEURON 등의 예제는 직접 계산한 결과를 불러옵니다. 이때 컨트롤은 저장된 시간 단계나 결과를 선택하며, 계산 입력을 바꾸려면 포함된 레시피를 다시 실행합니다. U²Net·YOLO 모델은 재실행 시에만 내려받아 캐시합니다. nanoGPT는 작은 원본 문장 집합으로 직접 학습한 손실 곡선과 생성 결과를 보여 줍니다. Mitsuba의 CPU 렌더, Draco 압축·xatlas UV 펼치기·libigl 변형, 폰트 조형·래스터화, JPEG 압축과 PySSTV 신호도 직접 계산한 결과로 비교할 수 있습니다. Go의 gg·ln·pt 렌더와 단백질 리본, C/C++의 볼록 껍질·다각형 분할·스파이로 곡선도 포함합니다. Go 모듈과 C/C++ 원본 소스는 재실행할 때만 다운로드해 캐시합니다. C/C++ 레시피는 소스 체크섬을 검증하며 로컬 컴파일러가 필요합니다. QMsolve·GWpy·SunPy의 과학 계산, LAMMPS 입자·SUMO 교통·유체 시뮬레이션, SAM 2.1 Tiny의 CPU 영역 분할도 직접 실행한 결과를 제공합니다. SAM 2의 모델과 소스는 재실행할 때 검증해 캐시합니다. 단어 배치·H3 격자·타일 병합·복셀화·스프링·윤곽·그래프 예제는 브라우저에서 컨트롤에 따라 다시 계산합니다. SDF 표면, 로봇 경로, 디더링·삼각형 근사·내용 기반 이미지 축소 예제에는 직접 실행한 결과와 재실행 레시피가 있습니다.

Rust 예제는 Kurbo·Lyon·Cavalier Contours의 곡선 계산, OpenSimplex2 지형, Fidget 단면, Truck 입체 모델링을 직접 실행한 결과를 제공합니다. Vello·Velato는 이 Mac의 Metal GPU에서 직접 렌더한 결과입니다. 포함된 Cargo 잠금 파일로 재실행하며 크레이트는 재실행 시에만 다운로드·캐시합니다.

FastNoise Lite·libnoise 지형, Voro++ 셀, RVO2 이동 경로, Skeleton Tracing 중심선과 MSDFgen 거리장도 원본 C++를 직접 실행한 결과입니다. DaisySP·Maximilian·Pink Trombone 예제에서는 직접 합성한 1초 음원을 선택해 들을 수 있습니다.

CSG.js 입체 불리언, NDWFC 타일, p5-hershey-js 획 글꼴, Fullik 관절, FloMat 중앙축 예제는 원본 JavaScript를 Node.js에서 직접 실행했습니다. Python 레시피가 검증된 소스를 캐시하고 Node.js로 재실행합니다.

Box2D·Bullet·Jolt의 반동 시뮬레이션, OpenSubdiv 세분화, Embree CPU 광선 질의도 원본 엔진을 빌드해 직접 계산했습니다. 이 레시피들은 CMake를 설치하고 소스와 네이티브 빌드를 캐시합니다. 캐시가 있어도 계산은 매번 실행하며 첫 빌드에는 시간이 걸릴 수 있습니다.

Leaflet·Sigma·3D Force Graph·MapLibre GL·deck.gl 예제는 가상 도형과 그래프를 원본 렌더러로 그립니다. 지도는 실제 거리 데이터나 외부 타일을 사용하지 않으며 계정이나 API 키도 필요 없습니다. canvas-sketch는 원본 매니저로 드로잉을 다시 그리고 React Spring은 실제 솔버를 고정 시간 간격으로 계산합니다.

GFPGAN v1.4 얼굴 복원은 공개 NASA 사진을 잘라 만든 세 손상 입력을 CPU에서 직접 계산했습니다. 입력·복원·원본 크롭을 비교할 수 있으며 약 349 MB 모델과 소스는 재실행할 때만 검증해 캐시합니다.

Doom 불꽃·VoxelSpace 지형·Ten Minute Physics 진자·TinyRenderer는 필요한 원본 소스 파일만 검증해 캐시하고 직접 실행합니다. psrdnoise는 원본 GLSL을 GPU에서 실행합니다. Meep 파동 시뮬레이션은 CPU로 직접 계산했으며, 재실행에는 Conda와 Apple Silicon macOS가 필요합니다. 고정된 실행 환경은 첫 실행에만 받습니다. 필드 색상은 결과마다 따로 정규화됩니다.

geometry-central 표면 거리, HatViz 모자 타일, ORCA 클록, Spring-It-On 감쇠, RoutingKit 경로, Turing Patterns 반응 확산, PyTopo3D 위상 최적화도 원본 엔진으로 직접 계산했습니다. 레시피는 필요한 소스 파일만 검증·캐시해 재실행합니다. PyTopo3D는 GPU 없이 작은 격자를 60회 최적화한 데모이며 저장된 밀도와 재료 사용 비율을 함께 제공합니다.

SVGNest 배치, Ray Optics 렌즈, LibRaw 합성 RAW 현상, Tesseract OCR은 원본 엔진을 직접 실행한 결과와 재실행 레시피를 제공합니다. React Three Fiber 매듭과 Cesium 타원체는 브라우저에서 실시간 렌더링합니다. OCR 모델과 소스는 재실행 시에만 내려받아 캐시합니다.

MapGenerator 도로, triangulate-image 삼각분할, TensorFlow Playground 학습 경계, LIC 벡터장, aubio 음높이 예제도 원본 엔진을 직접 실행했습니다. 준비된 계산 결과를 고르고 레시피로 다시 실행할 수 있어요. p5.brush 획은 브라우저 WebGL2에서 실시간으로 그립니다.

CGAL 제약 삼각분할, COLMAP 두 시점 복원, Essentia 음향 분석, GPlates 합성 판 회전, SPlisHSPlasH 유체 충돌, PositionBasedDynamics 천 제약도 원본 네이티브 엔진으로 계산했습니다. 계산 결과만 필요할 때 받아 보고, 환경을 준비하면 레시피로 재실행할 수 있어요. 합성 입력을 사용하는 작은 CPU 예제입니다.

PaddleOCR의 경량 탐지·인식 모델은 CPU에서, KataGo 신경망은 Mac의 Metal에서 직접 실행했습니다. ByteTrack은 합성 검출 입력의 누락을 견디며 ID를 유지합니다. 모델은 레시피 실행 시에만 고정된 파일을 검증해 캐시하며 갤러리에는 계산 결과만 내려받아요.

Faust는 공식 WASM 컴파일러로 WAV를 생성하고, FontForge는 직접 그린 글리프를 실제 TTF로 내보냅니다. AutoTrace는 래스터를 SVG로 추적하고 Tippecanoe는 합성 도로의 벡터 타일을 생성·디코딩합니다. 모두 원본 엔진을 직접 실행한 결과와 재실행 레시피를 제공합니다.

myPhysicsLab 원본 적분기의 진자 결과는 에너지 보존을 확인했습니다. glsl-fft는 원본 GLSL을 GPU에서 실행하며 주파수 조절 때마다 순·역변환 복원 오차를 검사해요.

MyPaint 원본 브러시, Astrometry.net 합성 별 좌표 풀이, Simbody 이중 진자, PyTorch3D 네이티브 메시 렌더링, diffvg 미분 래스터화를 직접 실행했습니다. 계산 결과와 재실행 레시피를 제공하며 큰 소스·실행 환경은 재실행할 때만 검증해 캐시합니다.

Penrose 제약 다이어그램, Context Free 재귀 도형 문법, geometry3Sharp 메시 구멍 복구, ConvChain 패턴 합성을 원본 엔진으로 직접 실행했습니다. 결과 선택과 재실행 레시피를 제공하며, gl-react는 두 단계 셰이더 그래프를 화면에서 실시간 실행합니다.

### Shadertoy 코드 가져오기

Shadertoy 셰이더 코드를 채팅에 붙여 넣고 "이걸 돌려 줘", "이걸 지금 장면에 섞어 줘"라고 해도 됩니다. Image 탭뿐 아니라
Common, Buffer A–D, iChannel 연결도 그대로 돌아갑니다(`ctx.utils.shadertoy`).

단, **오픈소스 라이선스가 적힌 셰이더만** 씁니다. Shadertoy의 기본 라이선스는 CC BY-NC-SA 3.0(비상업)이라 오픈소스가
아닙니다. 코드 맨 위에 MIT, CC0, Unlicense, 퍼블릭 도메인, Apache-2.0, BSD 같은 라이선스가 적혀 있을 때만 에이전트가
옮기고, 작성자와 링크, 라이선스를 코드와 대화에 남깁니다. 라이선스가 없으면 그 사실을 알려 주고 비슷한 느낌의 새 셰이더를
제안합니다.

## 2. 대화하며 고치기

결과를 보고 계속 말하세요.

- "더 느리게, 색은 노을처럼", "입자 수를 두 배로", "카메라를 위에서 내려다보게"
- "이 값들을 슬라이더로 빼 줘" — 바꾸고 싶은 값은 컨트롤(슬라이더, 노브, 2D 패드, 메뉴, 버튼, 색)로 받아서 손으로 만집니다.
- "이 이미지를 텍스처로 써 줘" — 이미지, 영상, 소리, 폰트, 3D 모델, 데이터를 끌어다 놓으면 에이전트가 씁니다.

### 다음에 해 볼 것

무엇을 더 해 볼지 막막하면 채팅 아래 **다음에 해 볼 것** 카드를 보세요. 지금 장면에 어울리는 기법을 골라 보여 줍니다.
2D 패턴이면 하이트맵 3D나 볼류메트릭 렌더링을, 3D 장면이면 PBR이나 SSAO, 패스 트레이싱을 권하는 식입니다.
카드를 누르면 에이전트가 그 기법을 지금 장면에 적용합니다.

**전체 목록에서 고르기**를 누르면 리믹스 목록이 열립니다. 기법 46개와 예제 전체가 카드로 있고, 여러 개를 골라
한꺼번에 섞을 수 있습니다. 예를 들어 픽셀 소팅 + Hydra 예제 + 비트 싱크를 고르고 "보라색 톤으로"라고 덧붙이면
에이전트가 하나의 작품으로 섞습니다. 기법에는 SSAO, 섀도 매핑, SSR, GPU 인스턴싱, 원근 워핑(코너 핀), 가우시안
스플래팅, 볼류메트릭 렌더링, 패스 트레이싱, 유체·천·보이드 시뮬레이션, 픽셀 소팅, 데이터모싱, 슬릿 스캔, CRT·VHS,
컬러 그레이딩, 비트 싱크(librosa), 스템 리액티브(Demucs), 핸드 트래킹, MIDI 매핑, 펜 플로터, 심리스 루프 등이 있습니다.
"GPU 무거움", "Python", "ML 모델" 표시가 붙은 기법은 느리거나 내 컴퓨터에서 도구를 실행합니다(실행 전에 묻습니다).
채팅에서 "다음엔 뭘 해 볼까?"라고 물어도 같은 목록에서 골라 줍니다.

모든 변경은 **History**에 썸네일과 함께 남아서, 마음에 들던 순간으로 언제든 돌아가 거기서 다시 갈라질 수 있습니다.
에셋 탭에서는 에이전트가 쓴 코드와 셰이더를 직접 읽을 수 있습니다.

## 3. 섞기

두 작업을 하나로 붙여 보세요.

- 예제의 **소개**를 열고 **섞기(Mix in)**를 누르면, 지금 열린 프로젝트에 그 예제의 씬과 에셋을 가져와 에이전트에게
  하나의 장면으로 섞어 달라고 요청합니다. 예: REBOUND 별의 궤적 위에 물감 소용돌이, L-시스템 정원에 Hydra 비디오 신스.
- 예제 목록에서 카드를 끌면 아래에 "여기에 놓으면 섞어요" 막대가 나타납니다. 거기에 놓아도 똑같이 섞입니다.
- 다른 사람이 보낸 `project.md`나 내가 예전에 만든 프로젝트의 일부를 채팅에 붙여 넣고 "이걸 지금 장면에 합쳐 줘"라고 해도 됩니다.

## 4. 라이브로 연주하기

- **입력:** 마우스와 키보드, 마이크와 오디오 파일(스펙트럼, 대역), 카메라, MIDI 컨트롤러, OSC(TouchOSC, Ableton,
  TouchDesigner 등). "MIDI 노브 1번으로 색을, 2번으로 속도를" 처럼 말하면 에이전트가 연결합니다. OSC는 데스크톱 앱이나 MCP에서 됩니다.
- **Perform:** 뷰포트 오른쪽 아래 **Perform**을 누르면 장면만 전체 화면으로 띄웁니다. 프로젝터나 두 번째 모니터로 보내고,
  컨트롤 패널과 MIDI·OSC·오디오로 연주하세요. Esc로 나옵니다.
- **Timeline:** 정해진 길이로 연출하려면 Timeline으로 바꾸고 컨트롤 값에 키프레임을 찍습니다.

## 5. 화면 비율과 영상으로 뽑기

뷰포트 오른쪽 아래 프레임 메뉴에서 화면 모양을 고릅니다: 창에 맞추기(Fit), 가로 16:9·4:3, 세로 9:16·4:5, 정사각형 1:1,
또는 1920×1080, 1080×1920, 3840×2160 같은 정확한 해상도, 직접 입력(예: `1280x720`, `21:9`). 정확한 해상도를 고르면 장면이
그 픽셀 수 그대로 렌더링됩니다. 프로젝트마다 기억합니다. 에이전트가 쓰는 장면은 중간에 크기가 바뀌어도(창 크기, Perform, 프레임 변경)
알아서 다시 맞추도록 만들어집니다.

**Rec** 버튼(또는 에이전트에게 "10초짜리 세로 영상으로 뽑아 줘")으로 녹화합니다.

- **Offline:** 처음부터 프레임 하나하나를 정확히 렌더링합니다. 원하는 크기(예: 1080×1920 세로, 4K)와 fps로, 느린 장면도 끊김 없이. MP4, WebM, PNG 연속 이미지.
- **Realtime:** 지금 화면을 그대로 녹화합니다. 마우스와 MIDI로 연주한 그대로 남습니다(WebM).

녹화한 영상은 프로젝트 에셋으로도 남아서, 다른 장면의 재료로 다시 쓸 수 있습니다. 이 저장소의 소개 영상도 예제들을 이렇게 녹화해서 만들었습니다.
