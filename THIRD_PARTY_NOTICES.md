# Third-party notices

Siljangnim (GPL-3.0-or-later) builds on the work of many people. This file lists it, with licenses and links to the
sources. It is generated by `node scripts/notices.mjs`; edit the sources (catalog, example.json) instead of this file.

## Reference list

The open-source catalog starts from **[index.opensource](https://indexopensource.com/index)** by 현 ([@hyun2xyz](https://www.instagram.com/hyun2xyz/), [Instagram](https://www.instagram.com/index.opensource/)).
`studio/src/catalog/index-opensource.json` keeps only facts and classification labels from it (412 projects: names, repositories, licenses, principle, medium, concept, field, input, keywords, index codes), never its descriptions. Most open-source examples were chosen from that list.
