# Transition between clips

## Setup

FFmpeg with libx264, lavfi, and the filters used below on PATH. Verified using ffmpeg version 9.0.2 Copyright (c) 2000-2026 the FFmpeg developers.

## Run

Original test patterns are generated by FFmpeg. Left is the baseline, right the edited result. The output is silent. Change the filter graph to adapt the edit; no external assets or accounts are needed.

```json
["ffmpeg", "-y", "-loglevel", "error", "-f", "lavfi", "-i", "testsrc2=size=640x360:rate=30:duration=4", "-f", "lavfi", "-i", "smptebars=size=640x360:rate=30:duration=4", "-filter_complex", "[0:v]split[a][b];[1:v]split[c][d];[a]trim=duration=3,setpts=PTS-STARTPTS[x];[x][c]concat=n=2:v=1:a=0[cut];[b][d]xfade=transition=diagtl:duration=1:offset=3[fade];[cut][fade]hstack=inputs=2[v]", "-map", "[v]", "-t", "7", "-an", "-c:v", "libx264", "-crf", "24", "-pix_fmt", "yuv420p", "-movflags", "+faststart", "out/comparison.mp4"]
```

## Verify

The shipped result was decoded end to end with `ffmpeg -i comparison.mp4 -f null -` and probed as 1280×360, 7.0 seconds. In the speed example the edited four-second input repeats twice within four seconds. In the transition example the wipe runs from 3 to 4 seconds.
